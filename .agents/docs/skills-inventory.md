## Dependencias externas y portabilidad

- OpenSpec requiere CLI. Playwright requiere CLI y navegador. verify-opengym usa PowerShell, Edge y un stack sano en localhost:8080 con UI en español y kg; su smoke no demuestra todas las funciones.
- Flujos de PR o trackers pueden requerir GitHub/GitLab/Jira/Confluence, credenciales y herramientas del cliente. El tracker configurado aquí es Markdown local: leer issue-tracker.md antes de publicar.
- Hay invocaciones específicas de clientes (Skill, Bash, Task o subagentes). Compartir ubicación no garantiza equivalencia de ejecución: usar una capacidad equivalente solo si está disponible y autorizada; informar bloqueos si falta.
- react-testing identifica agentes y slash commands upstream no instalados. Las referencias opcionales no son requisitos de carga del manifiesto.
- Los ejemplos de FastAPI/Postgres y herramientas de diseño requieren runtimes o servicios propios. Conservar una skill no introduce esas dependencias en el producto.
