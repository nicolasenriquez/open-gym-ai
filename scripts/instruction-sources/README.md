# Legacy exercise-instruction translation sources

These files retain translation provenance and terminology from the earlier
exercise dataset. The former pack-building and translation scripts are no longer
present; this directory is not the current contribution workflow.

For active exercise instructions and translations, edit the canonical
[catalogue](../../catalogue/README.md). Its build generates the frontend packs;
do not edit generated runtime files directly.

Keep these source files until their provenance and any remaining consumers have
been reviewed. Existing glossary and source-divergence notes remain reference
material, not evidence of native-speaker review.
