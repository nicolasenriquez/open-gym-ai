# Legacy exercise-name translation sources

These language files and review notes retain provenance from the earlier exercise
dataset. Their former per-language generators are no longer present; do not use
this directory as the current catalogue-editing workflow.

Current names and translations belong to
[catalogue/i18n](../../catalogue/README.md#translating). Use the catalogue's documented
validation/build commands and preserve exercise IDs. Do not edit the generated
frontend packs directly.

Retain the legacy JSON, terminology and review records until their consumers and
migration provenance have been checked. Machine-assisted translations must not be
presented as native-speaker reviewed without an actual human review.
