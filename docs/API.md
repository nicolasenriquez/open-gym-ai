# HTTP API

The complete openGym HTTP API — every route of `api/server.js`, with auth,
request/response schemas and the env-dependent behavior — is documented as a
hand-written OpenAPI 3.1 spec:

- **Canonical API document:** [`api/openapi.yaml`](../api/openapi.yaml)
- **Browsable static reference:** https://opengym.ch/api.html

The current handlers in `api/server.js` and their behavioral tests establish the
implemented behavior. Keep the specification aligned with them; a discrepancy
needs investigation, not an automatic change to either contract. The website
reference is generated by `scripts/build-api-docs.mjs`, without Swagger UI.

Lint it after changing routes:

```sh
pnpm dlx @redocly/cli lint api/openapi.yaml
```

## Python platform API v1

The partial Python port uses `/api/v1` exclusively, including its internal
health probes. Unversioned paths have no aliases or redirects. See the
[backend HTTP contract](../backend/README.md#http-api-v1) for frontend build
selection, available capabilities and probe visibility.

The Node OpenAPI document above remains the current Node contract and is not
a specification of Python route availability. Python does not expose Swagger,
ReDoc or an HTTP OpenAPI endpoint.
